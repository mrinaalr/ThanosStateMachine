# Defender read of Thanos's reward

Strange's tree answers *which futures survive*. Thanos's multi-channel
`R_G` answers *why he takes costly edges*. Guardians need both.

## Accuracy (what is / isn't claimed)

| Piece | Status |
|---|---|
| Goal G (half-cull / "balance") | High — stated repeatedly on screen |
| Means (stones → Snap → destroy) | High — plot spine |
| Purpose quotes | High — public film dialogue |
| Channel *shape* (progress / grief / lock-in / attainment) | Medium-high — fits the beats |
| Numeric weights (`w_c=1/5`, grief=`-1`) | **Calibrated illustration**, not measured psyche |
| Local utility on Vormir | Intentionally negative under those weights |

Weights are dials so the model can show the Gamora paradox. Do not treat
them as psychometric truth. Progress uses exact `Fraction(1,6)` so six
stones sum to `1` on every platform (CI once failed on float drift).

## How this helps Strange's policy

Policy search already says: under uniform play, ~2/3 of futures die at
the first contact node. Reward structure adds *why denial often fails*:

- **G never rewrites** when a stone is denied — path cost changes, goal
  does not. Expect regroup, not retirement.
- **Attachment cost ≠ veto.** Vormir hurts; he pays anyway if Soul is
  required for a completing path.
- **Instrumental mercy is not a second goal.** Sparing Stark buys Time;
  respect lines are real and still subordinate to G.
- **Capability ≠ enactment (the Wakanda window).** Stone progress reaches
  `1` when the Mind Stone sockets — that is capability, not the goal.
  `goal_attainment` books only at the Snap. Between last socket and
  enactment, denial still *prevents* rather than merely reprices. In
  Strange's tree this is `wakanda_strike`; in canon the window is thin
  (seconds), but it is the only one of its kind on the path.
- **Lock-in after Snap** moves the problem from prevention to
  remediation — Endgame's actual job.

So Strange optimizes over guardian choices; `R_G` tells the coalition
which offender edges are soft (grief), hard (destiny), or too late
(Garden). The SEP benefit-shape map (`guardian_interdiction_shapes()` /
`is-it-exploitation`) tags which tree nodes interdict extraction vs
enactment vs maintenance.

## Playbook for a later coalition (Doom-shaped threats)

New villains will not copy Thanos's gauntlet. Many will copy the
*reward shape*:

1. Fixed ideological G  
2. Finite set of enabling means  
3. Occasional attachment / personal cost that does not veto G  
4. A maintenance move that locks the completed harm  

Against that shape:

1. **Contest means early** — before the enabling set is complete.
2. **Budget for the enactment window** — a full gauntlet that has not
   snapped is still capability-complete; interdict enactment, not just
   acquisition.
3. **Do not bank on personal cost** stopping him; bank on removing the
   *need* for the costly edge (alternative completing paths for him, or
   yours).
4. **Ignore flattering bargains** that advance G.
5. **Pre-plan remediation** if lock-in is reachable — prevention-only
   plans lose the Endgame-shaped futures.
6. **Reuse the map, retune the lore** — same channels, new names.

`thanos-reward` prints the channel ledger and these leverage notes.
Strange's report remains the probability side of the same object.
